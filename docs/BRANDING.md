# 🎨 点到 FaceCall - 品牌标识

## 📛 品牌命名

### 中文名：点到
```
拼音：diǎn dào
含义：点名 + 到课
```

**深层含义**：
- **点**：老师点名的动作
- **到**：学生到课的状态
- **合义**：点名即知到课

**成语联想**：
- 说到做到（可靠）
- 点到为止（精准）
- 点石成金（智能）

---

### 英文名：FaceCall
```
发音：/feɪskɔːl/
含义：Face Recognition + Roll Call
```

**技术特征**：
- **Face**：人脸识别技术
- **Call**：点名考勤
- **组合**：人脸识别点名

## 📣 营销话术

### 电梯演讲（30秒）
```
点到是一款智能课堂考勤工具，
老师只需拍一张课堂照片，
10秒内就能完成点名并自动提交到教务系统。
它基于人脸识别技术，
准确率超过95%，
而且所有数据都在本地处理，保护学生隐私。
```

### 核心卖点（3个）
1. **快速**：10-20秒完成点名
2. **准确**：95%+识别准确率
3. **安全**：数据本地处理

```
传统方式 vs 点到

- 时间：3-5分钟
- 方式：逐个呼叫
- 问题：耗时、易漏、可造假

签到表：
- 时间：1-2分钟
- 方式：传递签名
- 问题：可代签、难统计

点到 FaceCall：
- 时间：10-20秒 ✅
- 方式：拍照识别 ✅
- 优势：快速、准确、防作弊 ✅
```

## 🎬 使用场景故事

### 场景1：体育课
```
时间：周二上午 10:00
地点：室外操场
人物：李老师，37名学生

[课前]
李老师："同学们集合！准备点名"
学生："老师，我们站好了"

[使用点到]
李老师拿出手机，拍了一张集体照
10秒后，手机显示："35人到课，2人未检测到"
李老师确认：张三请假，李四旷课

[提交]
李老师点击"提交"
考勤自动上传到教务系统

[上课]
李老师："好了，开始上课！"
（从点名到上课，只用了20秒）
```

### 场景2：大班讲座
```
时间：周四下午 14:00
地点：阶梯教室
人物：王教授，120名学生

[痛点]
传统点名需要5-8分钟
学生容易替签到

[解决]
王教授用点到拍了三张照（前/中/后区）
系统自动合并结果：118人到课
仅用30秒完成120人点名

[效果]
- 节省时间，增加授课时长
- 防止代签，真实考勤
- 自动提交，无需手工录入
```
